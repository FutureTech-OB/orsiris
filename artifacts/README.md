# Companion artifacts

- [Data_Recompute_v6.zip](Data_Recompute_v6.zip): data, CPU analysis, configurations and integrity verification.
- [Full_Reproduction_v6.zip](Full_Reproduction_v6.zip): the data package plus execution code, environments and small frozen assets.

Use GitHub's **Download raw file** button on each archive page, or clone this repository. Extract the archives into separate directories: each uses the root `submission_experiments/`. Follow [the reproduction guide](../docs/REPRODUCIBILITY.md).

Large model and SAE/J-Lens weights are not included. Original data labels and scientific records remain unchanged; machine-specific resource paths have been anonymized in the public copies.
